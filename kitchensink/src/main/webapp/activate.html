Account activation

After register, paste the activation token. Metrics go to Grafana dashboard 13.

Register via REST returns activationToken. Pending accounts cannot log in (not_activated).

Ready - paste a token and press Activate.

Outcomes

  • success - pending becomes activated
  • invalid_token - unknown token
  • expired - token past TTL
  • already_activated - activate twice
